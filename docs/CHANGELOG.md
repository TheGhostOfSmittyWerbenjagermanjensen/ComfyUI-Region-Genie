## Round 26 (Nov 17): autocomplete list behind the pop-up editor; gradient fill
- Asked for: (1) the tag autocomplete list was hidden behind the pop-up text box; (2) a gradient fill as another version of the Fill tool.
- (1) Cause: since round 12 the pop-up editors sit on top of the page at z-index 10000 (`.rg-pop`, `.rg-fpop`); the packs' lists are at 9999 (ComfyUI-Custom-Scripts) / 10000 (LoRA Manager). Fix: the lists Region Genie opens already carry the class `rg-ac`; `AC_CSS` now gives them z-index 10002. Test (stub page, a stand-in list element): ui_rows_popups. Confirmed afterwards with ComfyUI-Custom-Scripts installed in the test ComfyUI (the owner approved it), legacy and Nodes 2.0: its list (z-index 9999) opens over the pop-up and a pick is inserted; with the class taken off it is behind again. LoRA Manager's list isn't checked for real.
- (2) Owner's choices (multiple choice): the gradient is the region's **strength** (not a blend between two regions, not real colors in color_map); linear and radial; it fills the clicked area like Fill.
  - Data: a layer of its own with a bitmap op (the flood from the drag's start) and `grad: {k: "linear" | "radial", a: [lx, ly], b: [lx, ly]}` in layer units, so it moves / scales / turns / flips with the layer (`normGrad`, `mirrorOps`, `growLayer` keep it). Holes ignore it.
  - Editor: Fill button versions `linear` / `radial` (`LASSO_MODES.fill`, also in Settings > Canvas tools > Fill: default), `drag.mode === "grad"`, `gradFill()`, the drag's line drawn in `draw()`, `fadeLayerOn()` (destination-in with a canvas gradient on the layer's scratch) in `renderComposite` and `labelMap` (so the label map counts it from half strength).
  - Python: `layer_fade()`, `render_layers(..., soft)` and `soft_mask()`: the index map (color_map, boxes, layout prompt) takes the pixels at half strength or more; the `masks` output is the strength everywhere, also over the region below ("faint"). Everything fed from `masks` (regional LoRAs, keep-apart) gets the fade.
  - Decided while building: always a new layer (never added to the selected one: a layer has one gradient); merging uses the layer's full shape (the gradient is dropped); the region below keeps its full mask under the faint half (no cross-fade: that was the option not chosen).
- Tests: test_shapes_import (fade values linear / radial / turned, ownership at half strength, soft masks, a layer on top, holes), ui_footer_tools (menu, click without drag, drag, canvas fade, paint_data, reload, radial), ui_rows_popups (autocomplete on top), a real run in ComfyUI (CPU): masks -> Mask Picker -> image: 251 / 127 / 31 / 0 along the line; real_fields_popups, real_tooltips, real_settings, real_run_wildcards.
- Not tested: what a faded mask does to a real generation (LoRA strength, attention) on a GPU; LoRA Manager's list on top of the pop-up (ComfyUI-Custom-Scripts' is confirmed).
