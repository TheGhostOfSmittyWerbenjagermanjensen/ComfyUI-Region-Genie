# Wildcards (needs ComfyUI Impact Pack)

With **ComfyUI Impact Pack** installed, every text field of the node (scene_prompt_positive / negative / background, the region prompts and the text to render) and of **Regional LoRAs** (positive_prompt, negative_prompt, the rows' words) takes Impact Pack's wildcard syntax, filled by Impact Pack's own code when the workflow runs, exactly as its *ImpactWildcardProcessor* does: `__name__` (a random line of `wildcards/name.txt`, or a YAML key), `{red|blue|green}`, `{2$$a|b|c}` and the rest. The wildcard files are Impact Pack's (its `wildcards` folder and the paths in its settings). A prompt that arrives as MOSS / Ideogram JSON (e.g. Regional LoRAs' `positive_prompt` from the Region Genie node) is left as it is. Without Impact Pack, the text is used as typed and the node notes it.
- **Seed:** the field with the {⁎} icon in the bottom bar (Regional LoRAs: top right). The button next to it sets what happens after each run, like ComfyUI's *control after generate*: 🔒 fixed, 🎲 randomize (the default) or +1 increment. It only counts while a field has wildcards (it's dimmed otherwise, and the node stays cached between runs). By default every field uses the seed as it is, so the same wildcard in two fields usually picks the same value; **Settings > Region Genie > Wildcards > A seed per field** gives each field its own seed instead.
- **What it became:** after a run, a field whose wildcards were filled gets a gold edge on the left, and its tooltip shows the text that was used; the canvas labels show it too (until you edit the field). The 👁 button next to the seed previews the current seed without running.
- **Use the filled text:** to keep a result and tweak it, use the ⤓ button by the field in its pop-up editor (the ⤢ button in the field's corner), or right-click the seed: **Use the filled text in all fields**. The wildcards are replaced by the text they produced (region prompts: one undo step).
- **Adding a wildcard:** type `__` in any prompt field for a list of your wildcards (↑ ↓, Enter or Tab, Esc), or use the {⁎} button at the top of a pop-up editor to pick one (it inserts at the cursor; its last entry reloads the wildcard files).
- With the **LLM Prompt Enhancer**, the wildcards are filled first, so the LLM rewrites the filled text (a new pick means a new LLM call).
