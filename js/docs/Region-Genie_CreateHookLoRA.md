# Create Hook LoRA (Quantized)

A drop-in replacement for ComfyUI's Create Hook LoRA that also works with int8, fp8 and other quantized diffusion
models.

The full manual: [Regional LoRAs](https://github.com/TheGhostOfSmittyWerbenjagermanjensen/ComfyUI-Region-Genie/blob/main/docs/regional-loras.md#create-hook-lora-quantized).
